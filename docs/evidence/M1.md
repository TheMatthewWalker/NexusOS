# M1 — Nexus Core v0.1 acceptance evidence

M1 needs Core and the CLI working against **real** inference engines, not
only the mock used by Core CI. `scripts/acceptance/m1-live.sh` is the
reproducible procedure, with 16 checks. It covers health and system
inventory, deterministic provider selection, a non-empty answer from a real
Ollama model, a real managed llama.cpp server (start on demand, answer,
stop on unload), meaningful errors (missing model, stopped engine, blank
prompt, unknown provider), cloud fail-closed paths, the Unix-socket default
with no TCP listener, 0700/0600 state permissions, startup rejection of a
non-loopback endpoint, and the absence of the API token and prompt text
from Core logs.

## How to reproduce

```bash
dotnet publish src/NexusOS.Core/NexusOS.Core.csproj -c Release -o out/core
dotnet publish src/NexusOS.Cli/NexusOS.Cli.csproj -c Release -o out/cli
ollama pull qwen2.5:0.5b          # any pulled model works
NEXUS_OLLAMA_MODEL=qwen2.5:0.5b \
NEXUS_LLAMA_SERVER_BIN=/path/to/llama-server \
NEXUS_LLAMA_MODEL_PATH=/path/to/model.gguf \
  bash scripts/acceptance/m1-live.sh
```

The two llama.cpp variables are optional. Without them the llama.cpp checks
are skipped. CI runs the full procedure in the **M1 Live Model** workflow
with `qwen2.5:0.5b` downloaded from the Ollama registry. llama.cpp loads
the same GGUF blob, and the result is written to the job summary.

protocol and lifecycle path, not model quality.

## Gate still requiring the operator: live cloud answer

A live cloud answer needs a paid API key, which must never be placed in CI.
Run this once on your own machine:

```bash
secret-tool store --label="NexusOS OpenAI" app nexusos provider openai-compatible   # paste key, then Ctrl-D
NEXUS_CLOUD_EGRESS_ALLOWED=true dotnet out/core/NexusOS.Core.dll &
dotnet out/cli/NexusOS.Cli.dll use openai-compatible
dotnet out/cli/NexusOS.Cli.dll ask "Reply with the single word: ready"   # expect a non-empty answer
secret-tool clear app nexusos provider openai-compatible                  # optional: then expect "credential missing"
```
