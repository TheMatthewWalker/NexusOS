# M4 — Guardian rollback evidence

## Mechanism

1. `nexus-guardian-stage --decision <hash>` (root) does the following:
   - claims a permitted broker decision, once;
   - re-checks that the running generation still matches the candidate's baseline;
   - snapshots configured user data (a failed backup aborts staging);
   - sets the system profile and runs `switch-to-configuration boot`, never `switch` or `test`;
   - sets GRUB's `saved_entry` to the baseline and a **one-time** `next_entry` to the candidate.
2. Every generation boots with `panic=N boot.panic_on_fail`, so a boot that
   fails resets by itself. GRUB has already consumed `next_entry`, so it
   starts the baseline with no human input.
3. `nexus-guardian-boot-check.service` runs after the next boot:
   - **Candidate running and healthy** (`multi-user.target` active, no failed units, required units active): it becomes the default.
   - **Candidate running but unhealthy:** the baseline is restored for the next boot.
   - **Baseline running** (the trial failed): the baseline profile is restored.
4. The CI scan allows profile and bootloader commands only in
   `stage_executor.py` and `boot_check.py`, and forbids `switch`, `test` and
   `dry-activate` even there.

Run locally under QEMU/TCG (no KVM), nixpkgs 26.05, Linux 6.18.56. All four
subtests passed:

2. Healthy trial confirmed and kept across a reboot (636 s).

## Physical-hardware drill

Run this on a **spare** NixOS machine that uses GRUB, with
`services.nexus-guardian.staging.enable = true`:

1. Note `readlink -f /run/current-system`.
2. Build a deliberately broken variant of the host. Add
   `boot.kernelParams = [ "init=/nexus-intentionally-missing-init" ];` to a
   copy of its configuration and build it with
   `nix build .#nixosConfigurations.<host>.config.system.build.toplevel`.
3. Submit an allowlisted change through `nexus`, approve it at the root
   console, and sign an attestation naming the broken toplevel with a
   builder key trusted only on this machine.
4. Run `nexus-guardian-stage --decision <hash>` and reboot. Do not touch the
   keyboard.
5. Expected: the broken boot panics, the machine resets, the original
   generation boots, and
   `tail /var/lib/nexus-guardian/staging.jsonl` shows `fell-back`.
   Record the machine model, firmware (BIOS or UEFI) and timings here.
