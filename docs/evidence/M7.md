## Found by installing for real

- The login screen's greeter account is a system user with no writable home, but it still got a Core, which crashed in a loop. Core now runs only for people's accounts (`ConditionUser=!@system`), and the installer test fails if Core crashes after boot.
- The installer terminal had no monospace font, so its text was spaced out. Fixed by installing JetBrains Mono as the desktop's monospace font.
- Locking the flake inside `nixos-install` changed the flake mid-build. It is now locked first.
